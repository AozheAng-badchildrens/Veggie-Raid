# Veggie-Raid
A fan made PVZ mini game. <br></br>
You can play the game directly at [Veggie Raid](https://www.greenfoot.org/scenarios/29862).

## Features 
<ul>
<li>A conveyor belt level</li>
<li>Three levels of difficulty</li>
<li>Two fun mini games</li>
</ul>

## Installation instructions
<ol>
    <li>Download and install [Greenfoot](https://www.greenfoot.org/download).</li>
    <li>Download the `gfar` file available in the repository.</li>
    <li>Open the `gfar` file with Greenfoot.</li>
</ol>
